How it works

Answer a few questions, or pass --yes. You get two services that already know about each other.

01 · ASK

Choose your parts

Web, core or both. Sign-in providers, database, Stripe tiers and prices, and an optional Coolify project.

ss create <name>
02 · COPY

Copy the templates

The bundled Next.js and FastAPI templates are copied, named after your project and given their ports.

<name>-web/ <name>-core/
03 · WIRE

Wire the services

A fresh local Postgres password, matching database and Redis URLs, and each side's URL for the other.

.env (never committed)
04 · RUN

Start and build

docker compose, migrate, then npm run dev and uvicorn. With a Stripe key it also creates your products and prices.

--demo: no accounts

What you get

Every screenshot below is the scaffolded app, running locally.

Pricing from the tiers you chose

Plans are read live from Stripe, with a monthly and yearly toggle. Checkout comes with a 7-day trial, plus the customer portal and a subscription webhook.

  • Middleware sends users without a plan to /pricing
  • With a key, ss create makes the products for you

Onboarding that reaches the API

Connect an account, write a short bio, add a phone number, start a trial. Saving the phone number stores it in Postgres and queues a welcome message on the FastAPI core through Redis.

  • Clerk sign-in with Google, GitHub, Microsoft or Slack
  • Drizzle schema and migrations

Settings, ready to extend

Profile details, notification preferences and the current plan, with a link to the Stripe portal.

A FastAPI core with a queue

Health checks for Postgres and Redis, a Redis message queue, Celery beat workers, and an optional Gemini summary and Mailtrap email pipeline. Each optional service stays off until you add its key.

Quick start

You need Python 3.10+, uv (or pip), Node 20+ and Docker.

# install the CLI
$ git clone https://github.com/enzihub/shadowstone && cd shadowstone
$ uv tool install .

# scaffold, with local stand-ins for Clerk and Stripe
$ ss create acme-notes --yes --demo

# web
$ cd acme-notes/acme-notes-web
$ docker compose up -d
$ npm install && npm run db:migrate && npm run db:seed
$ npm run dev                # http://localhost:3000

# core
$ cd ../acme-notes-core
$ docker compose up -d redis
$ uv run uvicorn main:app --port 8000   # /docs
